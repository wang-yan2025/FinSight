# FinSight 智研投 · 比赛演示手册（离线可复现）

## 环境准备

```bash
pip install -r requirements.txt     # 无需额外依赖；LLM 可选
streamlit run app.py
```

- **无需网络**：所有演示均可离线复现。演示 A 需本地缓存
  `data/cache/SH600519_{income,balance,cashflow}.csv`（首次联网拉取后自动生成；
  缓存 12 小时内命中"本地缓存"，过期后重新联网刷新）。
- **无需 LLM Key**：未配置 `FINSIGHT_LLM_API_KEY/BASE_URL/MODEL` 时，系统生成
  确定性基础备忘录（定性章节显示"待生成"），不出现伪造的 AI 分析文本。
  配置后 LLM 仅撰写定性章节，且输出经结构/引用/数字匹配校验，均带
  "尚未经独立核验"标注。
- **数据边界**：财务数据来自东方财富结构化报表（经 akshare），真实公司与
  真实期间；演示 B/C 中的错误声明为**人工构造并明确标注的模拟错误**，
  仅存在于评测样本（`finsight/eval/samples.py`），不会写入真实数据。

## 演示 A：正常投资研究（真实缓存数据）

1. 「财报分析（方向2）」→ 输入 `600519` → 查询。
   预期：三大报表（时点/累计口径标注）、指标概览（特殊同比状态如
   "由盈转亏"显式标注）、趋势图、R1–R4 风险信号（均为风险提示）。
2. 「买方备忘录（方向6）」→ 加载数据 → 生成备忘录。
   预期：九章节 + 附录A 证据清单（E-REV-2026Q2 式证据 ID、期间、口径、
   来源）+ 附录B 历史风险信号完整清单；第五节仅突出近 8 个季度并注明
   时间范围与总数。
3. 「研报纠错（方向5）」→ 核验本会话备忘录。
   预期：分状态（✔通过/✘不通过/○无法核验/⚠需人工复核）展示；
   引用 ID、公司、期间、字段逐项校验；快照指纹显示。

> 页面显示的报告期以数据实际最新期间为准（演示时不念固定期间数字，
> 以页面与导出文件中的期间标注为准）。

## 演示 B：发现错误并受控修复（内置样本，明确标注模拟错误）

方式一（命令行，最快）：

```bash
python -c "from finsight.eval.bench import run_bench; [print(k, '=', v) for k, v in run_bench().metrics.items()]"
python -c "from finsight.eval.expanded import run_expanded_bench; [print(k, '=', v) for k, v in run_expanded_bench().metrics.items()]"
```

方式二（页面完整闭环）：「投研工作台（闭环演示）」→ 输入 `600519` →
1 加载数据 → 2 生成备忘录并独立核验 →（如需错误演示，参考方式一样本的
模拟错误）勾选确定性修订建议 → 3 生成修订稿并再核验 → 查看前后对比
（已确认修复/口径澄清/新引入错误/提取丢失四类）→ 下载 8 个导出项。

预期要点：错误修正建议的数值一律来自独立参考值（不凭空造数）；
修订必须人工勾选确认；V1 原始版本只读；两轮核验共用同一参考快照。

## 演示 C：系统知道自己的能力边界（不编造结论）

评测样本中直接可见（`finsight/eval/samples.py` 的 S20/S23/S25/S18）：

- 期间超出数据范围（S20）→ `insufficient_evidence`（注明"数据不足≠虚假"）；
- 定性断言无引用（S23"行业领先的竞争壁垒"）→ `insufficient_evidence`；
- 隐含主语/中文数字/科学计数法（S25/S27/S28）→ 保守**不提取**，
  单独计入"提取覆盖缺口"，绝不默认通过；
- 裸期间标签（S18"2024Q4 同比 3.75%"）→ `needs_review`（数值与某口径一致
  也不判通过，提示标注口径后复核）；
- LLM 内容 → 永远携带"结构/引用/数字匹配检查≠事实核验"标注。

## 固定样本评测指标（小样本，如实声明）

两套评测：`bench.py`（9 句演示样本）与 `expanded.py`（**31 条人工标注样本**
= 28 条核验声明样本 + 3 条修订场景样本，修订场景以独立子实验执行、
每条恰计一次）。最新实测：提取覆盖率 24/24（分母 = S01–S24 预期可提取）、
错误检出 12/12（分母 = 12 条预期 fail 的错误样本）、**false pass 0**、
修订三场景全部按预期识别、不可提取样本 3/3 如实未提取（单独统计）。
**以上为人工构造固定样本上的确定性统计，用于演示与回归核对，
不代表对任意真实研究报告的普遍准确率。**统计分母与口径见
`finsight/eval/expanded.py` 模块注释。

## 常见故障与排查

| 现象 | 原因与处理 |
|---|---|
| 查询报"利润表不可用/接口取数失败" | 无网络且缓存缺失/过期 → 联网刷新一次，或确认 `data/cache/` 存在 |
| 备忘录定性章节显示"待生成" | LLM 未配置或调用失败（确定性内容不受影响） |
| 数据来源显示"本地过期缓存" | 联网失败后回退旧缓存，数值期间以页面标注为准 |
| 上传文件被拒 | 仅支持 .md/.docx ≤10MB，损坏文件会明确报错 |
