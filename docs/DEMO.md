## 演示 B：错误发现与受控修订（内置样本，离线）

运行 `python -m finsight.eval.bench`（或运行测试 `pytest tests/test_eval_bench.py`）
使用固定样本报告（含人工植入错误）：

1. 金额错误（480 亿 vs 参考 415 亿）→ fail，确定性修订建议 `480亿元 → 415亿元`；
2. 单位/指标错配（净利润 415 万元）→ fail，按参考值重写 `-200,000万元`；
3. 状态词错误（扭亏为盈 vs 实际由盈转亏）→ fail，人工建议（不改写）；
4. pp/% 概念混淆 → fail（确定性拦截）。

页面演示同路径：「投研工作台（闭环演示）」→ 加载 `600519` → 生成并核验 →
勾选确定性建议 → 生成修订稿（V2）并再核验 → 查看前后对比
（已修复/口径澄清/新引入错误/提取丢失分类）→ 下载修订稿与修订记录。

## 基础评测指标（固定样本确定性统计）

运行 `python -c "from finsight.eval.bench import run_bench; print(run_bench().metrics)"`：
提取覆盖率、错误检出率、false pass、修订建议正确率、受控修复数、
修订引入新错误数、人工复核比例。分母与统计口径见 `finsight/eval/bench.py`
注释；指标由 Python 从固定样本计算，不含虚构值。

**两个实验场景（勿混淆）**：

1. **评测基准（`finsight/eval/bench.py`，部分采纳）**：9 句固定样本报告
   （8 条可提取声明 + 1 条定性），仅采纳 2 条数值类确定性修订建议，
   状态词错误与 pp 概念混淆**未采纳**并如实保留 fail——对应指标：
   建议正确率 2/2、受控修复 2、修订稿再核验仍 fail 2、
   人工复核比例 2/9（超范围期间 + 定性断言）。
2. **闭环演练（全采纳，`tests/test_workflow.py` + 演示脚本）**：固定数据的
   完整备忘录（首轮 11 pass + 注入 2 错误）→ 采纳全部 2 条确定性建议 →
   再核验 13 pass / 0 fail、无回归。

以上均为**小样本固定数据**上的确定性统计，用于演示与回归核对，
**不代表对任意研究报告的普遍准确率**。
