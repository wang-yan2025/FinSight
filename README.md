# FinSight 智研投

金融 AI 投研项目（**纯规则内核 + 可选 LLM 定性层**），整合三个比赛方向并形成完整闭环：

| 方向 | 功能 | 状态 |
|---|---|---|
| 方向2 | 上市公司财务报告分析 | ✅ 报表/指标/趋势/风险信号页面 |
| 方向6 | 买方投资备忘录编制 | ✅ 证据关联备忘录 + MD/DOCX 导出 |
| 方向5 | 研究报告纠错核查 | ✅ 独立核验引擎（V1–V5）+ 核验报告 |
| 闭环 | 生成 → 核验 → 受控修订 → 再核验 → 对比 | ✅ 投研工作台 + 固定样本评测 |

## 核心能力

- **数据层**：东方财富三大报表（经 akshare），本地 CSV 缓存（12h TTL，断网回退过期缓存），来源标注基于缓存文件写入时间（保守措辞）。
- **财务引擎**：字段映射与标准化（12 字段实测确认、累计/时点口径实证）；单季还原；盈利/偿债/营运/成长四类指标；R1–R4 风险信号（阈值可配置，输出均为风险提示 risk_hint）。
- **备忘录**：确定性骨架（事实全部来自结构化数据并关联证据 ID）+ 可选 LLM 定性章节（OpenAI 兼容接口，输出经结构/引用/数字匹配校验，携带"尚未经独立核验"标注）。
- **独立核验**：参考值由标准化数据 + 引擎独立重算（不采信报告自身内容）；五态结果（pass/fail/insufficient_evidence/unable_to_verify/needs_review）；快照差异检测；MD/DOCX 核验报告。
- **闭环工作台**：人工确认的受控修订（确定性建议=参考值+期间+口径确定且位置唯一；V1 只读、修订必产新版本）；再核验独立重跑；前后对比（修复/回归/口径澄清/提取丢失分类）。
- **评测**：固定人工标注样本（`finsight/eval/`），确定性统计提取覆盖率、错误检出率、false pass、修订三场景；小样本声明如实标注。

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py                        # 四页面：财报分析/备忘录/核验/工作台
python -m pytest tests -q                   # 完整离线测试
python -c "from finsight.eval.expanded import run_expanded_bench as r; print(r().metrics)"
```

演示手册（三条路线、降级行为、故障排查、能力边界）：[docs/DEMO.md](docs/DEMO.md)。

## 项目原则

1. 财务计算全部由程序完成，公式与数据来源可追溯；不编造数据、测试结果或完成状态。
2. 关键结论关联证据 ID（东财结构化字段 ≠ 公告 PDF 页码，溯源边界如实声明）。
3. 所有风险信号均为风险提示，不构成造假认定；"通过"仅覆盖成功提取并核验的声明。
4. 核验与备忘录数据同源（东方财富），为计算路径独立比对，非跨数据源交叉验证。
5. 真实 LLM 联网调用已验证（DeepSeek，2026-10-12 实测：定性章节生成→校验→核验全链路通过）。
