# FinSight 智研投

金融 AI 投研项目（**纯规则版**，LLM 通道预留），整合三个比赛方向：

| 方向 | 功能 | 状态 |
|---|---|---|
| 方向2 | 上市公司财务报告分析 | 指标计算引擎已实现（分析页面待开发） |
| 方向6 | 买方投资备忘录编制 | 阶段3 待实现 |
| 方向5 | 研究报告纠错核查 | 阶段4 待实现 |

## 当前状态（阶段1 完成，2026-10-10 验收）

- 项目骨架 + Streamlit 导航入口（`app.py`）
- 数据层：东方财富三大报表（经 akshare），本地 CSV 缓存（12h TTL，断网回退过期缓存）
- 冒烟测试：600519 三大报表拉取通过（资产负债表 103 期×319 列、利润表 103 期×203 列、现金流量表 99 期×254 列，最新报告期 2026-06-30）
- 字段映射与标准化（`finsight/finance/field_mapping.py`）：12 个标准字段全部实测确认；利润表/现金流量表为累计口径（已实证）
- 单季还原与指标计算引擎（`finsight/finance/quarterly.py`、`indicators.py`）：盈利/偿债/营运/成长四类指标，缺失显式标注原因

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py                     # 界面
python tests/smoke_em_statements.py      # 数据层冒烟测试（需联网），可带股票代码参数
pytest tests -q                          # 纯逻辑单元测试
```

## 数据说明

- 数据来源：东方财富公开接口（经 akshare 1.19.1），仅用于比赛研究。
- `data/cache/` 下的 CSV 为拉取快照（gitignore，不入库），列名为东财原始英文字段。
- 未获取到数据的字段一律显式标注缺失，不进行任何编造或插值。

## 项目原则

1. 财务计算全部由程序完成，公式与数据来源可追溯。
2. 报告关键结论必须关联证据（报表字段+报告期），否则标注"待核验"。
3. 纯规则版先行；LLM 通道后续以配置项接入，不改动整体架构。
